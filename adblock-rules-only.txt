# 七猫 / 通用广告拦截 补丁规则（2026-09-28 维护）
# 用法：Shadowrocket → 配置 → 当前配置 → 编辑 → [Rule] 段顶部粘贴
#
# 背景：sr_top500_whitelist_ad.conf 带 update-url，每次订阅更新都会
#       覆盖手写规则，因此把自定义规则单独存档于此，更新后重新粘贴。
#
# 语法要点（这轮踩过的坑）：
#   DOMAIN-SUFFIX,x   只匹配 x 本身与 *.x —— 匹配不到 a6-remad.x 这类连字符前缀
#   DOMAIN-KEYWORD,x  任意位置包含 x —— 专治 -remad.qm989.com 这种命名
#   DOMAIN,x          仅精确匹配 x
#   不支持通配符 *（如 pangolin-sdk-toutiao* 是无效规则，会被静默忽略）
#   REJECT=拒绝；REJECT-DROP=拒绝并丢弃（更彻底，减少客户端重试）
# ============================================================
