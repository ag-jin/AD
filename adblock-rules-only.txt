# ================= 自定义广告拦截规则（维护：2026-09-28）=================
# 语法要点（这轮踩过的坑）：
#   DOMAIN-SUFFIX,x   只匹配 x 本身与 *.x —— 匹配不到 a6-remad.x 这类连字符前缀名
#   DOMAIN-KEYWORD,x  任意位置包含 x —— 专治 -remad.qm989.com 这种命名
#   DOMAIN,x          仅精确匹配 x
#   不支持通配符 *（pangolin-sdk-toutiao* 是无效规则，会被静默忽略）
#   REJECT=拒绝；REJECT-DROP=拒绝并丢弃（更彻底，减少客户端重试）
# =========================================================================
